# 可复用工具与证据复核

[首页](../../README_zh.md) · [候选方案编排](orchestration.md) · [English](../en/hyra2-design.md)

[Hyra 2.0 官方文章](https://hunyuan.tencent.com/research/hyra2)发布于 2026-11-02，
提出从解决单个问题走向研发可复用工具。正文与图 2 区分研究决策、Worker 执行、
原始证据复核、项目状态、Agent 记忆和共享知识。
DataEvolver 借鉴这些设计，不打包 Hyra 的代码、模型或运行时，也不引用其结果作为本项目收益。

## 适合当前 Base 的机制

| Hyra 2.0 设计 | DataEvolver 对应与范围 |
|---|---|
| 为后续任务研发工具 | 现有 Operator、原生 Worker Profile 与编译计划可表达可复用数据工作流。工具变化需要新版本或绑定，并生成新的冻结 Goal。单个案例成功不能证明迁移收益。 |
| 区分研究决策与执行 | Workbench 主 Agent 可协调子会话，Campaign Controller 负责执行、预算与恢复。本项目没有复现 Overall/Mission/Worker 项目管理体系。 |
| 在新上下文中先复核原题与证据 | `dataevolver_delegate(mode="review")` 冻结明确的问题与选定执行观察，不复制作者消息。复核者报告发现与限制。 |
| 不同 Worker 使用不同模型 | 委派可选 `profile`，从主会话保存的配置中选择 Provider、模型和 thinking。省略时沿用子 Agent 默认值。 |
| 区分项目状态、工作上下文和可复用知识 | Campaign 与任务回执记录执行；Pi 历史和上下文快照服务当前会话；原有领域准入与 `CapabilityStore` 约束可复用能力。复核接口不会写入或晋升能力。 |

复核模式复用子进程限额、独立本地目录、上下文大小限制、摘要校验与只读桥接。
本改动没有新增模型默认值、端点、依赖、Controller 或知识数据库。

## 留下方法及其适用条件

交接候选 Operator、配方、排障方法或 skill 草稿时，子会话报告宜包含以下内容。
这是一项报告约定，不是新增知识格式或自动准入接口。

| 字段 | 复核所需内容 |
|---|---|
| 方法 | 修改的代码、工作流或配方，以及版本或摘要。 |
| 原因 | 促成修改的失败现象或成本。 |
| 适用条件 | 任务、模型与工具版本、数据假设和资源限制。 |
| 证据 | 原始回执、日志或轨迹路径，同时保留失败与成功。 |
| 检查与限制 | 读过什么、执行过什么、独立复现过什么，以及未知项。 |
| 复用边界 | 可复用的接口，以及需要重新生成的冻结绑定。 |

例如，Blender 导出修复可以留下候选 Worker Profile 与回执引用。
新的复核会话可检查源码与产物。实际渲染、环境校准、跨来源准入和训练收益是不同结论，
分别需要获准执行后取得的证据。

Hyra Books 区分观察、独立复现的发现和经人类确认的约定。
DataEvolver 不把这些名称新增为能力状态。执行快照属于观察，模型复核属于意见，
可复用的 `PROMOTED` 能力仍需要原有领域准入。团队约定沿用维护者审阅与批准流程。
模型意见一致不能证明独立复现、能力准入或团队批准。

目录数据准入见
[`catalog_knowledge.py`](../../src/dataevolver/harness/catalog_knowledge.py)，
训练工作流准入见
[`training_workflow.py`](../../src/dataevolver/harness/training_workflow.py)。
这些契约继续生效。只向 `CapabilityStore` 写入记录不能证明准入；不应直接修改状态字段来绕过检查。

可迁移方法可以作为 skill 候选提交。Workbench 仍禁用宿主机 skill 自动加载。
Agent 编写的 skill 属于待审阅源码，不会自动安装为指令。

## 暂不移植的设计

Hyra 还描述了持久化优先级与依赖队列、定时唤醒、Research Board 消息、分层记忆和 Books。
这些机制适合长期项目，但需要新的持久化协作契约。本改动保留有界 FIFO 派发与显式恢复，
重启后不会静默重放效果不明的任务。三层 Agent 组织、通知服务、审批平台、自动算力分配
和评价器共同演化均未引入。

预期作用是让交接可追踪，并减少复核者提前接触作者结论。
新上下文不能保证无偏判断。原题由调用者提供，原生工具仍有宿主机权限，引用文件也可能变化。
快照摘要标识的是传入上下文，不能证明证据为真或引用产物不可变。
候选质量、跨任务复用、算力成本和下游训练收益需要分别测量。

本改动仅接受静态审查。附带契约测试未运行，未通过项目任务、模型、引擎或 CI 验证运行可用性。
